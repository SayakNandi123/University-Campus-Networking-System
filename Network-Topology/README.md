# Network Topology

This folder contains the Cisco Packet Tracer project and the complete network topology of the University Campus Networking System.

## Files

- University_Campus_Network.pkt
- Network_Topology.png

The topology consists of:

- Main Campus
- Branch Campus
- Cloud Network
- Email Server
- Web Server
- FTP Server
- Dynamic Routing
- VLANs
- DHCP
- DNS
- Layer 3 Switching
