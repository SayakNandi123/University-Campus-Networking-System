# Network Topology

This folder contains the Cisco Packet Tracer project file and the network topology diagram for the **University Campus Networking System**.

## Files

- **University_Campus_Network.pkt** – Cisco Packet Tracer project containing the complete network implementation.
- **Network_Topology.png** – Visual representation of the overall campus network architecture.

## Topology Overview

The network includes:

- Main Campus and Branch Campus
- Cloud Router for inter-campus connectivity
- Router-on-a-Stick for Inter-VLAN Routing
- Layer 3 Switching
- VLAN segmentation
- RIP v2 dynamic routing
- DHCP Server
- DNS Server
- HTTP Web Server
- FTP Server
- Email Server (SMTP/POP3)
- End-to-end communication between network devices

The Packet Tracer project can be used to explore the network design, device configurations, routing behavior, and implemented network services.
